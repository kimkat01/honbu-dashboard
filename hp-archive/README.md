# 各園HPの保存版（hp-archive）

本部ダッシュボードの「各園HP」（hp-preview.html）の「表示する時点」で選べる、過去のHPの画像です。
HPを更新したら、更新前・更新後の画面を残すために、ここへ画像を追加します（古い画像は消さずに残します）。

## 置き場所とファイル名

```
hp-archive/園コード/日付_pc.jpg   … PC版（パソコンで見た画面、ページ全体）
hp-archive/園コード/日付_sp.jpg   … スマホ版（スマホで見た画面、ページ全体）
```

- 例：三郷中央を 2026年12月1日に保存 → `hp-archive/S13/2026-12-01_pc.jpg` と `hp-archive/S13/2026-12-01_sp.jpg`
- 日付は「年-月-日」（半角、月と日は2けた）。
- 園コード：S01 しおどめの森／S02 八潮駅北／S03 京急蒲田駅前／S04 小規模認可／S05 江戸川中央／S06 春日部／S07 越谷／S08 八潮茜町／S09 ふれあい守谷／S10 つくば／S11 稲城／S12 久喜／S13 三郷中央／S14 ふれあい八潮／Y01 八潮しおどめ／Y02 守谷しおどめ／Y03 なかよし
- jpg のほか png も使えます。PC版だけ・スマホ版だけでも置けます。
- 置いたあと数分で、プルダウンに日付が出ます（画面を開き直してください）。
- いちばん新しい日付のスマホ版が、「現在」のスマホ版として表示されます。

## 撮り方（Chrome）

1. 園のHPを Chrome で開き、一度いちばん下までスクロールして写真を読み込ませてから、いちばん上に戻る。
2. F12 で開発者ツールを開き、Ctrl＋Shift＋P →「full size screenshot」と入力 →「Capture full size screenshot」。これがPC版。
3. スマホ版は、開発者ツールの左上のスマホのアイコン（Ctrl＋Shift＋M）で「iPhone」などを選び、同じく「Capture full size screenshot」。
4. 保存された画像の名前を上のルールに変えて、GitHub の `hp-archive/園コード/` に「Add file → Upload files」でアップロードする。
